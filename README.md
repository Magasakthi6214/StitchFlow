StitchFlow - Custom Tailoring & Order Management Portal
StitchFlow is a single-page web application designed for custom tailoring management, customer measurement tracking, and order handling.
Features
Session Authentication Display: Explicit banner status showing Signed In: [Name] ([Role]) or Not Signed In (Guest).
Centralized Measurements Engine: Synchronizes body metrics (chest, waist, length) across Customer Directory, Measurements Log, and Order forms in real-time.
Geospatial Tailor Search & Comparison: Proximity-based tailor filtering with multi-tailor side-by-side comparison tables.
Minimalist Garment Gallery: Subtle dress, jacket, and fabric showcase grid on the landing page.
Local Persistence: Full client-side state retention using browser localStorage.
